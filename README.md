# Juha Park — Audio & Music Portfolio Starter

A colorful, responsive portfolio starter made with plain HTML, CSS, and JavaScript. It is designed for GitHub Pages and does not require a build step.

## Files
- `index.html` — page content and structure
- `style.css` — colors, layout, responsive styling
- `script.js` — mobile navigation and current year
- `assets/` — place your own photos, artwork, and other local assets here

## Customize before publishing
1. Search `index.html` for `YOUR_EMAIL@example.com` and replace it with the email address you want to publish.
2. Replace sample project descriptions with accurate details about your own work.
3. Add photos you have permission to share. Avoid publishing private information or photos of other people without permission.
4. Add real links to your music or embedded players where the template currently has placeholder links.
5. Update the page title and meta description if you want.

## Preview on your computer
Open `index.html` in a browser. You can also open the folder in a code editor such as Visual Studio Code.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your actual GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under the build and deployment settings, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. After the deployment finishes, visit `https://YOUR-USERNAME.github.io`.

GitHub Pages sites are public on the internet, so check every file and detail before publishing. Your GitHub username is part of the free site address. You can use a custom domain later, but it is not required.

Official guide: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
